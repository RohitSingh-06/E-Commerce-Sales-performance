# E-Commerce-Sales-performance
Data Analytics Project
Overview

This project demonstrates an end-to-end data analytics workflow, from loading and exploring raw data to creating interactive dashboards and presenting business insights.

The project includes:

Loading and analyzing a dataset using Python
Exploratory Data Analysis (EDA)
Data cleaning and preprocessing
Building an interactive Power BI dashboard
Creating a detailed analytical report
Preparing a presentation using Gamma

The project uses a structured dataset containing relevant business data for analysis.

Project Workflow
1. Load the Dataset

The dataset is imported into Python using Pandas. Initial checks are performed to understand the structure, columns, data types, and overall size of the dataset.

2. Exploratory Data Analysis

EDA is performed to identify patterns, trends, relationships, and potential data quality issues.

Key activities include:

Understanding dataset dimensions
Checking data types
Analyzing numerical and categorical variables
Identifying missing values
Detecting duplicates and outliers
Creating visualizations
Identifying important trends and patterns
3. Data Cleaning

The dataset is cleaned and prepared for analysis.

Typical steps include:

Handling missing values
Removing duplicate records
Correcting data types
Standardizing column values
Handling inconsistent or invalid data
Treating outliers where appropriate
4. Power BI Dashboard

The cleaned dataset is imported into Power BI to create an interactive dashboard.

The dashboard focuses on:

Key Performance Indicators (KPIs)
Trends and comparisons
Category-wise analysis
Interactive filters and slicers
Business-focused visualizations
5. Analytical Report

A report is created to document the analysis and communicate the key findings.

The report covers:

Business problem/objective
Data preparation
EDA findings
Key insights
Dashboard observations
Business recommendations
6. Presentation

A concise presentation is created using Gamma to communicate the project findings in a professional and recruiter-friendly format.

The presentation highlights:

Project objective
Dataset overview
Methodology
Key insights
Dashboard
Recommendations
Final conclusions

How to Run
1. Clone the Repository
git clone <repository-url>
cd data-analytics-project
2. Install Dependencies
pip install -r requirements.txt
3. Run the Python Analysis

Open the Jupyter Notebook:

jupyter notebook

Run the cells in data_analysis.ipynb to perform data loading, EDA, cleaning, and analysis.

4. Open the Power BI Dashboard

Open the .pbix file located in the dashboard/ folder using Power BI Desktop.

5. Review the Report and Presentation

The final report and Gamma presentation are available in their respective folders.
